# Zero to Shipped completion checklist

## Eligibility

- [ ] Participant is at least 18.
- [ ] Country of residence is not excluded by the official rules.
- [ ] Participant is not an Amazon/AWS employee or an excluded household member.
- [ ] Builder Center profile is complete and uses a monitored email address.
- [ ] This is the participant's only entry.
